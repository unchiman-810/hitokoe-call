# ひとこえ通話 ― 同じネットワークでできるテキスト通話

相手に「通話」をかけて、つながったらお互いが**打っている文字がリアルタイムで見える**アプリです。
文字で電話しているような感覚で話せます。サーバー不要・インストール不要で、
同じ Wi-Fi / LAN の PC 同士が直接つながります。

## ダウンロード
**[最新版の HitokoeCall.exe はこちら(Releases)](../../releases/latest)**

1. `HitokoeCall.exe` をダウンロードして、好きな場所に置きます(Windows 10 / 11、64bit)。
2. ダブルクリックで起動。初回は相手に表示される名前を聞かれます。
3. 「Windows によって PC が保護されました」と出たら、「詳細情報」→「実行」を押してください。
   (個人で作ったアプリで、有料の電子署名を付けていないために表示されます)
4. **Windows ファイアウォールの確認が出たら「プライベート ネットワーク」で許可してください。**
   許可しないと、相手からの着信が届きません。

通話する相手にも同じ exe を起動してもらうと、数秒で一覧にお互いが表示されます。

## 使い方
- **かける**: 一覧から相手を選んで「📞 通話する」(ダブルクリックでも可)
- **受ける**: 画面右下に着信ウィンドウが出て音が鳴ります。「応答」でつながります(30秒で不在着信)。
- **話す**: 下の「あなた」の欄に打った文字は、打っている途中からそのまま相手の画面に見えます。
  相手が打っている文字は上の欄に映ります。Enter で自分の文字を消して、次の言葉へ。
- **履歴は残りません**: 画面にも、ファイルにも、言葉は残りません。打って消したらそれきりです。
- **リアクション**: 👍 ❤️ 🎉 😂 😮 を押すと、相手の画面にふわっと表示されます。
- **切る**: 「切る」ボタン。
- **見た目**: 「設定 → 見た目 (白 / 黒)」で切りかえられます(最初は黒)。
  一覧の画面はすぐ変わり、通話の画面は次の通話から変わります。
- **×ボタン(一覧の画面)**: 「いいえ」で最小化して着信を待ち続けます。「はい」で終了します。
- 通話中にほかの人からかかってきた場合は、相手に「通話中」と伝わります。

## つながらないとき
- 両方の PC が同じ Wi-Fi / LAN にいるか確認してください。
- ファイアウォールでこのアプリを許可しているか確認してください。
- 学校・会社のネットワークでは、PC 同士の通信やブロードキャストが止められていることがあります。
  相手に「設定 → 自分の IP アドレス」(または画面下の「IPをコピー」)で IP をコピーして送ってもらい、
  「設定 → IP アドレスで相手を追加…」に貼り付けると直接つながる場合があります。
- 一覧の相手の IP は、右クリック →「IP アドレスをコピー」か、選んで Ctrl+C でコピーできます。

## しくみ
- 相手さがし: UDP 50722 番ポートのブロードキャストで「ここにいるよ」を3秒ごとに知らせ合う
- 通話: かけた側から相手の PC へ TCP で直接つなぎ、入力中の文字とリアクションを送り合う
- 暗号化はしていません。同じネットワークの中で、人に見られて困る内容は送らないでください。
- 設定の保存先: `%APPDATA%\HitokoeCall`(会話の内容は保存しません)

## Python で動かす(開発用)
Python 3.10 以降があれば、追加のライブラリなしで動きます。

```
python hitokoe_call.pyw
```

`--profile a` / `--profile b` を付けて2つ起動すると、1台の PC で2人分を動かして通話をためせます。

exe の作り方:

```
pip install pyinstaller
pyinstaller --onefile --noconsole --name HitokoeCall hitokoe_call.pyw
```
